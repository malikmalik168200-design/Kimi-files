# AeroBridge Share Preview — Design Ground Truth

This is a **reference-preservation project**, not a redesign. The existing AeroBridge Flight Deck Console prototype is the ground-truth visual and interaction reference.

## Ground-truth reference

Preserve the deep-navy operational console, Vector Blue route accents, green/amber status semantics, monospace readouts, persistent sidebar on desktop, compact mobile command rail, terminal-first Practice surface, and the sequence `Progression → Practice → Assessment → Growth → Tracking → Scenarios → Next Action`.

The preview is presentation-first: it must be easy to open and share, while keeping the prototype’s route navigation and local mock interactions visible. Do not add backend, authentication, payment, engine architecture, or real metrics.

## Style Decisions

The visual language remains **Flight Deck Console**: evidence-first, operational, dark, structured, and slightly cinematic. Preserve asymmetric sidebar/content composition, restrained gradients and atmospheric route imagery, high-contrast operational text, and compact utility controls. Prefer contextual labels such as Start, Resume, Review, and Retry over generic SaaS wording.

The preview should expose enough interaction to demonstrate the product loop, but every mock or illustrative state must remain clearly local and non-production.
